## 📌 ¿Cómo agregar tu presentación y su link interactivo?

Como este repositorio tiene **GitHub Pages** activo, cualquier archivo HTML que subas se puede abrir como una página web real con solo hacer un clic.

### 1. Nomenclatura del archivo
Guarda tu archivo HTML directamente dentro de esta carpeta `presentations/`:
```text
presentations/Tu_Nombre_Apellido.html
```
*(Si usas imágenes o assets locales, agrégalos dentro de la subcarpeta `presentations/imgs/`).*

### 2. Estructura de la URL pública en GitHub Pages
La URL para abrir tu presentación interactiva sigue este formato:
```text
https://Dusuan.github.io/intern-club/presentations/<Nombre_De_Tu_Archivo>.html
```
> **Nota sobre espacios y acentos:** Si el nombre de tu archivo tiene espacios, reemplaza los espacios por `%20` en el enlace (ejemplo: `Juan%20Manuel%20Sandoval%20Ramírez.html`).
